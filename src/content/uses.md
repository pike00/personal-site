The tools I reach for. A living list.

## Editor &amp; terminal

- **Editor:** VS Code
- **Shell:** zsh, with starship, atuin, and fzf
- **Multiplexer:** tmux

## Languages &amp; tooling

- **Python:** managed with [uv](https://docs.astral.sh/uv/)
- **JavaScript / TypeScript:** pnpm
- **Task runner:** [just](https://github.com/casey/just)
- **Dotfiles:** [chezmoi](https://www.chezmoi.io)

## This site

- **Framework:** [Astro](https://astro.build) + React + Tailwind CSS
- **Hosting:** Cloudflare Pages
- **Analytics:** self-hosted [Umami](https://umami.is)

## Home lab

A small fleet of machines running Docker behind Traefik, tied together with Tailscale.
